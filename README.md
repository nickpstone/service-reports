# Vet1 Service Reports

Installable PWA for creating Vet1 equipment service and repair reports quickly from reusable historical templates.

## v1
- Historical clinic autocomplete, with new clinic details stored locally in the browser
- Equipment-specific issue, repair and testing shortcuts
- VP50/SP50 templates based on historical Vet1 reports
- Photo capture/upload
- Live Vet1-style report preview
- Direct PDF export
- Installable PWA and offline app shell

No completed reports are stored by the app in v1; exported PDFs remain with the technician.

## Hosting
This is a static app suitable for GitHub Pages. Enable Pages for the repository and deploy from the main branch/root.

Historical seed data was derived from the supplied archived and 2026 Vet1 service-report PDFs.
